C3PO: College Collaboration Club for Professional Opportunities 

This project was developed during our time as members of C3PO, a year long program where students develop virtual reality experiences for K-12 classrooms by working directly with teachers.
The program is mentored by Dr. Edgar J. Rojas-Muñoz from Texas A&M University.

We collaborated with Forrest Medcalf, an Introduction to Engineering teacher at FISD, to develop a hands on virtual reality demonstration to learn simple machines. The VR experience features a medieval themed scene with various simple machines like gears, levers, and wheels and axles. Students are tasked to experiment with different simple machines to complete objectives while learning how different variables affect force.

This project was submitted and accepted into the SIGGRAPH 2025 Faculty Submitted Student Work Symposium. 

The project demonstration can be found here: https://education.siggraph.org/wp/fssw/siggraph-2025-fssw/
